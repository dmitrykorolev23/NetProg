# NetProg

Практическая работа № 3. Королев Д. А., группа 25ПИ2.

В репозитории представлены два сетевых клиента:

- `daytime` — получение даты и времени от сервера по протоколу UDP;
- `echo` — отправка сообщения серверу и получение его обратно по протоколу TCP.

## Запуск daytime

```bash
cd daytime
make
./daytime
```

## Запуск echo

```bash
cd echo
make
./echo "Hello, echo service!"
```
