# NetProg
Практическое задание №3. Королев Д.А. 25ПИ2
.
В репозитории представлены две программы-клиента сетевых служб:
1. `daytime` — UDP-клиент для получения даты и времени от сервера;
2. `echo` — TCP-клиент для отправки текстового сообщения серверу и получения этого сообщения обратно.

## UPD-клиент daytime
Параметры подключения:
- IP-адрес сервера: `172.16.40.1`;
- порт: `13`;
- протокол: UDP.

Сборка и запуск:

cd daytime
make clean
make
./daytime

## TCP-клиент echo

Сборка и запуск:

```bash
cd echo
make clean
make
./echo "Hello, echo service!"
